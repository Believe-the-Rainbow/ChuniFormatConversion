# c2s2ugc

某 16 分区下落式音游的街机谱面（`.c2s`）→ 社区客户端曲库（`.ugc`）转换器。

- **转换 + 打包**：谱面、音频（BGM）、封面、背景图一次入库，按街机原分类建文件夹
- **兼容表**：[COMPATIBILITY.md](COMPATIBILITY.md) — 全部 6698 张官方谱面的实测结果，按分类建表，可查你的曲目是否与街机官方一致 / 有哪些已知偏差
- **计数对拍**：内置纯 Python 物量计数器（与目标端本体真实解析器在全部
  **6698 张官方谱面**上逐张验证零分歧），转换后自动与街机官方 `T_JUDGE` 数字对拍，
  不一致时给出明确警告，由你决定是否入库
- **零游戏依赖**：本体不含、也不需要任何游戏代码；不改动你的游戏本体
- 纯 Python 标准库实现（唯一可选第三方依赖 Pillow，用于封面/背景转 PNG）

> **本工具非官方、无任何关联背书**：与该音游的权利人（开发商等）以及任何
> 社区客户端/模拟器项目（无论其名称、版本或分支）的开发者、维护者、社区均

## 快速开始

### 准备

1. Python 3.8+（`python --version` 能跑就行）
2. `pip install pillow`（封面/背景 DDS→PNG 需要）
3. 下载 [vgmstream-cli](https://vgmstream.org/)（音频解码），把 `vgmstream-cli.exe`
   连同其运行库放进 `lib/vgmstream/`。没有它：谱面照常转换，但歌曲没有 BGM。

### 启动

双击 **`启动转换.cmd`**（或命令行 `python convert.py`）。首次运行会弹出两次文件夹
选择框：

1. 选 **游戏主程序所在的文件夹** —— 工具自动定位 `data/music` 曲库
2. 选 **街机数据根目录**（包含 `music/` 与 `cueFile/` 的那层，通常是 `A000`）

路径记在 `config.json`，以后不再询问；输 `p` 可重设。

### 选谱转换

```
song ID (逗号分隔): 0083
♪ <曲名> — <曲师>
  分类: <原分类>  (入库到「<原分类>」文件夹)
难度 [1=BAS 2=ADV 3=EXP 4=MAS 5=ULT 6=WE a=全部]: 4
  MAS(紫) (14.6)
  ALL   1874 / 1874 ✓
  TAP   1041 / 1041 ✓
  ...
  ✓ MAS 已入库
```

- **song ID** 就是曲库文件名里 `CHU_` 后面的四位数字
  （如 `[MAS]CHU_0083.ugc` → `0083`），可以逗号分隔一次转多首
- 难度快捷对应：`1` 绿谱 / `2` 黄谱 / `3` 红谱 / `4` 紫谱 / `5` 黑谱 / `6` 宴会场
- 入库位置：`data/music/<街机原分类>/<曲名>/`——按街机原版分类建文件夹，
  客户端会自动识别为独立分类

命令行方式（可脚本化）：`python convert.py --songid 0083,8129 --diff 4 --yes`

## 计数警告是什么意思

每张谱转换后，工具用内置计数器数一遍转换产物的五种音符（TAP/HLD/SLD/AIR/FLK），
与 c2s 内嵌的街机官方物量逐项对照：

- **完全一致** → 直接入库
- **不一致 → 明确警告 + 询问**：默认不入库，确认后才写入

出现偏差时，转换出的谱面**可能与你在街机上实际游玩的版本存在出入**——主要
出现在含 air-slide / air-hold / 波形链的谱面，属于转换目标端与街机之间固有
的规则差异，并非哪一方的"错误"。全量对拍结果：约 86.5% 的谱面（5796/6698）
与街机官方数字逐项一致，其余 902 张存在偏差（偏差量即警告里显示的数字）。
是否入库由你决定。

**按难度拆分如下——整体一致率由低难度谱面拉高，请以你实际转换的难度为准**：

| 难度 | 谱面数 | 与街机官方逐项一致 | 一致率 |
| --- | --- | --- | --- |
| 绿谱 BAS | 1631 | 1607 | 98.5% |
| 黄谱 ADV | 1631 | 1558 | 95.5% |
| 红谱 EXP | 1631 | 1419 | 87.0% |
| 紫谱 MAS | 1631 | 1098 | 67.3% |
| 黑谱 ULT | 106 | 63 | 59.4% |
| 宴会场 WE | 68 | 51 | 75.0% |
| **合计** | **6698** | **5796** | **86.5%** |

（分歧集中在含 air-slide / air-hold / 波形链的谱面；偏差量逐谱不同，明细见
[COMPATIBILITY.md](COMPATIBILITY.md) 的分类表。）

## 目录结构

```
convert.py            交互入口（song ID / 对拍 / 警告 / 入库）
启动转换.cmd          双击启动
lib/
  c2s2sus.py          .c2s 解析（含宴会场、超车道、金头等机制）
  ugc.py              UGC 文本生成（v8/v9、EXFIELD、金头标记）
  pack.py             入库打包（音频/封面/背景）
  ugccount.py         纯 Python 物量计数器（6698/6698 验证）
  stagebg.py          背景图查询
  vgmstream/          ← 你自放的 vgmstream-cli.exe（不入库）
scripts/              验证复现工具（语料转换 + 官方对拍，可选，见下）
config.json           首次运行生成（个人路径，不入库）
```

## 验证（可选复现）

`scripts/` 可对你**自己拥有的** HDD 复现计数对拍：

```bash
python scripts/convert_corpus.py --hdd <A000目录> --out out/corpus_ugc
python scripts/tj_regress.py     --hdd <A000目录> --corpus out/corpus_ugc
```

1. 全量把 HDD 谱面转成 UGC 文本（约 76 秒 / 6698 张）
2. Python 计数器逐张与 c2s 内嵌的街机官方物量对拍 → 预期结果：
   **5796/6698（86.5%）逐项一致**，其余 902 张存在 air 家族偏差（即
   [计数警告](#计数警告是什么意思)的数据来源，全部为游戏本体与街机的
   真实规则差异）。

计数器与目标端本体解析器行为逐张等价（6698/6698 零分歧）由作者另行完成
全量验证；该验证所涉及的解析器代码属于游戏衍生内容，本仓库不包含、不提供、
也不描述其获取方式。
